• New: Analyze with AI. Right-click a folder or file and choose "Analyze with AI" to ask Claude, ChatGPT or Perplexity what it is and whether it is safe to delete. Gemini, Le Chat and Duck.ai open with the prompt on the clipboard, and "Copy Prompt" works with any assistant.
• New: Interactive session in Terminal. If Claude Code, Codex CLI or GitHub Copilot CLI is installed, DiskRings can start it in the folder, in plan or read-only mode or with approval for every change. Configuration files and instructions in the folder can influence the AI, so use this only for folders whose contents you trust. You still delete only in DiskRings, with the Trash and undo.
• Privacy: The prompt contains the path, sizes and the names of the largest items. Your user name, full name and computer name are replaced by placeholders, your home folder by "~". DiskRings asks before the first send and makes no network connection itself.
