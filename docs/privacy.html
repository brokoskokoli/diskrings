Privacy Policy

Applies to all versions of DiskRings (Mac App Store and direct download). Last updated: October 20, 2026.

In short

DiskRings does not collect, store or share any personal data. Everything it reads and saves stays on your Mac. Facts about a folder leave your Mac only if you explicitly click “Analyze with AI”, and then through your browser or the AI tool you chose, never through DiskRings itself.

No data collection

DiskRings has no analytics, no telemetry, no crash reporting service, no advertising and no user accounts. The developer receives no information about you or how you use the app.

Network connections

DiskRings itself never sends file names, sizes or scan results anywhere (see “Analyze with AI” below for what happens when you ask an AI assistant).

  • Mac App Store version: DiskRings never connects to the internet. Updates come from the App Store.
  • Download from GitHub: To keep itself up to date, DiskRings asks GitHub whether a new version is available. It downloads a small file (appcast.xml) from github.com when you choose “Check for Updates…” and, if you allow automatic checks, about once a day. The request only identifies the app and its version; no information about you, your Mac or your files is sent, and no system profile is collected. As with any web request, GitHub sees your IP address (see the GitHub Privacy Statement). Updates are downloaded from GitHub and installed only if their signature matches. DiskRings asks before checking automatically; you can turn it off at any time in Settings → General → “Automatically check for updates”.

Analyze with AI (only when you click it)

Right-clicking an item and choosing an entry under “Analyze with AI” hands a prompt about that item to an AI assistant of your choice. Nothing is sent before you click, and DiskRings makes no network connection for this.

  • What the prompt contains: the item’s path, kind, size, number of files and folders, last modification date, the names and sizes of the largest items inside, a rough breakdown by file type, the app it probably belongs to (its bundle ID and whether that app is installed), in a comparison the change since the snapshot, and your macOS version. Your user name, full name and computer name are replaced by placeholders such as <user>, and your home folder by ~. All other folder and file names are passed on unchanged. File contents are never included.
  • AI on the web: DiskRings opens your default browser. For some services the prompt is part of the link; for others, or when it is too long for a link, it is copied to the clipboard and you paste it yourself. It is always exactly the prompt that “Copy Prompt” gives you. The service you chose receives the prompt, and its own privacy policy applies.
  • Copy Prompt: only copies the prompt to your clipboard (the same prompt the web assistants receive).
  • Interactive session (download from GitHub only): DiskRings opens Terminal in the folder and starts the AI command-line tool you chose and installed yourself (Claude Code, Codex CLI – including the one in the ChatGPT app – or GitHub Copilot CLI), in plan or read-only mode or with approval for every change, never with automatic approval, and where the tool allows it without MCP servers and settings from the folder. The tool receives a start prompt with the same facts (the largest items, without the file type breakdown) and can read files in that folder; its own privacy policy applies. Configuration files and instructions in the folder (for example from downloaded projects) can influence how the AI behaves, so use sessions only for folders whose contents you trust. The script that starts it is stored only briefly in a temporary folder that only you can read, and deletes itself.
  • Before the first send, DiskRings explains what is passed on, separately for web services and sessions; “Show the Privacy Notice Again” in Settings → AI brings both explanations back. There you also choose which assistants appear in the menu.

What stays on your Mac

  • To show disk usage, DiskRings reads the names and sizes of files and folders you choose to scan. It does not read file contents.
  • Scan snapshots (folder structure and sizes, used for comparing scans) and settings are saved locally in the app’s own storage. In the Mac App Store version this is the app’s container, ~/Library/Containers/de.stefanrichter.DiskRings. You can delete snapshots in the app at any time. Removing the app does not remove this data on macOS: it stays in ~/Library/Containers/de.stefanrichter.DiskRings until you delete that folder (in the Finder, choose Go → Go to Folder…, enter ~/Library/Containers, and move the folder “DiskRings” or de.stefanrichter.DiskRings to the Trash after quitting the app).
  • In the Mac App Store version, DiskRings only reads folders and volumes you select in the Open dialog or drag onto its window. It remembers these choices on your Mac so it doesn’t have to ask again; you can remove them in Settings.
  • “Move to Trash” moves items you choose to the macOS Trash. It asks for confirmation first; for smaller items you can turn this off with “Don’t ask again”. Nothing is deleted permanently by the app: items always go to the Trash, and you can put them back (with Undo in DiskRings or “Put Back” in the Finder) until you empty the Trash.
